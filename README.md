# Basic Movies/Series/Games search website
## Como executar
Obter chave API no website 'https://www.omdbapi.com/'  
Copiar o conteúdo do ficheiro api.example.js para um novo ficheiro com o nome de "api.js" e inserir a sua chave API  
Abrir index.html


Ou 


Corre o comando abaixo com o terminal aberto na página do projeto:
```
cd app-filmes
cat api.example.js > api.js
rm api.example.js
nano api.js
```
Troca 'A_TUA_CHAVE_AQUI' pela tua chave API, dentro das aspas.

Ctrl + O  e Enter de seguida para guardar  
Ctrl + X para sair do editor


Abrir index.html
